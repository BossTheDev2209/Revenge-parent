# Engines — คู่มือใช้งานสำหรับคนเติมเนื้อหา

3 ระบบนี้ **โค้ดเสร็จแล้ว** ทีมมีหน้าที่เติมเนื้อหาอย่างเดียว ไม่ต้องแตะโค้ดเลย

| Engine | ทีมทำอะไร | อ่าน |
|--------|-----------|------|
| 🗣️ **Dialogue** | เขียนบท NPC ในไฟล์ `Content.Dialogue.*` | [dialogue.md](dialogue.md) |
| 🎬 **Cutscene** | เขียน ending 6 ไฟล์ + วาง Part กล้อง `Cam_*` | [cutscene.md](cutscene.md) |
| 🔊 **Audio** | วาง Sound ใน SoundService + Part โซน `Zone_*` | [audio.md](audio.md) |

## หลักการร่วมของทั้ง 3

1. **แยกเนื้อหาออกจากโค้ด** — เนื้อหาอยู่ใน ModuleScript/Instance ที่ตั้งชื่อตามกติกา โค้ดอ่านตามชื่อ
2. **ผิดแล้วเกมไม่พัง** — ชื่อผิด/ไฟล์หาย = `warn` ใน Output แล้วข้ามไป (ยกเว้นลบ comma ในไฟล์ Lua = ไฟล์พังจริง)
3. **เพิ่มของใหม่ไม่ต้องแก้โค้ด** — เพิ่มเพลง/เพิ่มบท/เพิ่มมุมกล้อง = วางของตั้งชื่อ จบ
4. **เทสคุมให้** — บอก agent ให้รันเทสหลังแก้ จะฟ้องทันทีถ้า format พัง

## ระบบอื่นที่ยังไม่มีคู่มือแยก
