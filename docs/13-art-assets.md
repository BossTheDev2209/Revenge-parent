# 13 — รูปที่ต้องวาดทั้งหมด (อิง PDF ครบ 10 หน้า, ปรับใหม่ 21 ก.ค. 2569)

**ใครใช้ไฟล์นี้:** คนวาดรูป (ทุกสาย) + agent ที่ต่อ UI

## ⚠️ อ่านก่อนวาด — ที่มาของทุกขนาดในไฟล์นี้

**1. Roblox ย่อรูปอัตโนมัติถ้าด้านยาวเกิน 1024 px** → **ห้ามวาดเกิน 1024 ในด้านที่ยาวที่สุด** วาด 1920 ไปก็โดนย่อเหลือ 1024 เสียเวลาเปล่า

**2. UI ในเกมมี 2 ระบบ ขนาดคนละเรื่อง:**

| ระบบ | อยู่ไหน | พื้นที่จริง | ตัวอย่าง |
|------|---------|------------|----------|
| **SurfaceGui** — แปะบน**จอคอมจริงในโลก** | UI PC ทั้งหมด (8 แอป + wallpaper + icon) | **canvas 1000 × 650 px** = จอ part 4 × 2.6 studs × 250 px/stud | icon แอป, wallpaper, หน้า Edit |
| **ScreenGui** — ลอยทับจอผู้เล่น | HUD, ปุ่ม RETURN, cutscene, เมนูหลัก | จอผู้เล่นจริง (~1920 × 1080) | หลอดใจ, progress bar, hotbar |

**3. สัดส่วนจอคอม = 4 : 2.6 = 1.538 : 1** (ไม่ใช่ 16:9!) → ภาพเต็มจอคอมทุกใบต้องเป็น **1024 × 666**

**4. วาดใหญ่กว่าที่แสดง ~1.5–2 เท่า** เพราะตอนกล้อง zoom เข้าจอ canvas 1000px จะถูกยืดเต็มจอ 1920px (ตัวเลขในตารางคิดเผื่อให้แล้ว วาดตามได้เลย)

**กติกา 5 ข้อ:**
1. **PNG พื้นหลังใส** ทุกไฟล์ (ยกเว้น wallpaper / background ที่ทึบได้)
2. ไอคอนเผื่อขอบใน ~6-8px กันโดนตัด
3. **ทุกไฟล์ที่ลงท้าย `_fill` ต้องเป็นสีขาวล้วน** — โค้ดคูณสีเอง (ใส่สีมาแล้วจะเพี้ยน)
4. ต้องอ่านออกบน**พื้นเข้ม** (HUD พื้นดำโปร่ง 25%)
5. อัปโหลดใน Roblox → เอา asset id ใส่ `ReplicatedStorage.Shared.UIAssets` → ไม่มีรูป = โค้ดใช้ emoji/ตัวหนังสือแทนอัตโนมัติ เกมไม่พัง

**ลำดับความสำคัญ:** 🅿️0 = ขาดไม่ได้ (กระทบภาพรวมทั้งเกม) | 🅿️1 = ทำให้ดูจริงจัง | 🅿️2 = มีก็ดี ไม่มีก็ส่งได้

## ขั้นตอนหลังวาดเสร็จ

1. Studio → **View > Asset Manager > Images > Import** ลากไฟล์เข้า
2. คลิกขวารูป → **Copy Asset ID**
3. เปิด `ReplicatedStorage.Shared.UIAssets` → วางใส่คีย์ที่ตรงกัน:
   ```lua
   hud_follower = "rbxassetid://1234567890",
   ```
4. **ห้ามเปลี่ยนชื่อคีย์** — โค้ดหาไม่เจอ (คีย์ที่ยังไม่มีรูป ปล่อย `""` ไว้ได้)
5. กด Play เช็ค — รูปไม่ขึ้นให้ดู Output ว่ามี warn อะไร

**Roblox moderation:** รูปที่อัปต้องผ่านการตรวจ ~นาที–ชั่วโมง | ห้ามใช้รูปมีลิขสิทธิ์/โลโก้จริง = **ผิดกติกาแข่ง ตกรอบ**
