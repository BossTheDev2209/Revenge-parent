## 1. โครงเฟส (Phase Gate)

เฟสตัดสินจาก **follower ปัจจุบัน** เท่านั้น **ไม่ผูกกับจำนวนคลิป**

| Gate | Milestone |
|------|-----------|
| เฟส 1 | 0 → 10,000 (ผ่าน beat 1K ระหว่างทาง) |
| เฟส 2 | 10,000 → 100,000 |
| เฟส 3 | 100,000 → 1,000,000 |

- Milestone canon: **1K → 10K → 100K → 1M** (absolute) — timeline % เป็นแค่ story beat
- ต้องถึง gate ก่อน story event เฟสถัดไปถึง unlock
- **ยกเลิกแล้ว:** แนวคิด "150 คลิป / เฟส 1 = 10 คลิป / เฟส 2 = 40 / เฟส 3 = 45"
  (เก็บไว้เป็น reference ตอน playtest เท่านั้น ไม่เขียนลงเกม)
- **ยกเลิกแล้ว:** limit คลิปต่อวัน (MAX_CLIPS_PER_DAY) — ไม่จำเป็นหลัง Bad End 1 เป็น optional

## 2. สูตร Follower ต่อคลิป

```
follower ที่ได้ = เลขสุ่ม base ของเฟส × VidQ multiplier × mental multiplier
                  แล้วมีโอกาส 12% ได้ viral spike ×4–8
```

**Base ต่อเฟส (สุ่ม):**

| เฟส | base |
|-----|------|
| 1 | 400 – 900 |
| 2 | 1,400 – 2,600 |
| 3 | 9,000 – 15,000 |

**VidQ multiplier** (จาก accuracy มินิเกมตัดคลิป เต็ม 200):

| Tier | Accuracy | Multiplier |
|------|----------|-----------|
| C | 0 – 50 | ×0.5 |
| B | 51 – 100 | ×1 |
| A | 101 – 150 | ×1.5 |
| S | 151 – 200 | ×2 |

> ใช้ label **C/B/A/S ทุกหน้า** — เลิกใช้ bad/normal/good/awesome แล้ว

**Edit more — lock 27 ก.ค.:** จอสรุป QTE มีปุ่ม `Edit more` = ตัด**คลิปใหม่**ต่อทันที ไม่ต้องออกไปเปิดแอปใหม่
เป็นปุ่มลัดล้วนๆ **ไม่ใช่การตัดคลิปเดิมซ้ำ** — คะแนนของแต่ละคลิปแยกกัน ตัดแล้วตัดเลย
ทุกรอบเสีย **ใจ −20 + นับ "ตัดคลิป 5 ติด"** ตามปกติ · ไม่มี cap จำนวนรอบ เพราะ mental คือ limit อยู่แล้ว

**Viral system:** ทุกคลิปมีโอกาส 12% → follower ×4 ถึง ×8 (สุ่ม)
ต้องมี VFX/SFX + popup "ไวรัลแล้ว!" ตอน trigger

## 3. Mental Bar

**Multiplier 3 โซน:**

| โซน | ผล |
|-----|-----|
| 70 – 100% | follower ×1.0 – ×1.25 (ยิ่งใกล้ 100 โอกาสได้โบนัสยิ่งสูง) |
| 40 – 69% | ปกติ ×1.0 |
| 1 – 39% | follower ×0.6 – ×1.0 (ยิ่งใกล้ 0 ยิ่งหักหนัก) |
| 0% | **Bad End ②** |

> Cap ที่ ×1.25 จงใจ — ไม่ให้ stack กับ viral (×4–8) + S tier (×2) จน pacing พัง

**ค่าเริ่มต้น:** 80% | **ลดตามธรรมชาติ:** 1% ทุก 4.5 วินาที
**ระบบ introduce ตอน:** phase 2

**สิ่งที่ลด mental:**
- ตัดคลิป −20
- เลือกข้อคุยกับ NPC แย่ −10
- เลือกข้อตอบ comment แย่ −5
- จ่ายค่าเช่าไม่ทัน −15

**สิ่งที่เพิ่ม mental:**
- เลือกข้อคุยกับ NPC ดี +15
- เลือกข้อตอบ comment ดี +10
- คลิปไวรัล +25
- Activity พ่อนคลาย: ออกกำลังกาย +20 / พักผ่อน +25 / กินข้าว +15

**Drain/Recovery Modifiers (lock 19 ก.ค. — user ตัดสิน):**

ความหมาย: ฝั่ง drain = คูณอัตรา drain | ฝั่งดี = **คูณ delta ฝั่งบวก** (ฟื้นแรงขึ้น)
ซ้อนกัน = คูณกันหมด **cap ที่ ×3** ทั้งสองฝั่ง

| Modifier | คูณ | ติดเมื่อ | หายเมื่อ |
|----------|-----|---------|---------|
| อดนอน | ×1.5 drain | ตื่นต่อเนื่องครบ 20 ชม.เกม | นอน |
| Canon event | ×1.25 drain | milestone event trigger | ครบ 1 วันเกม (24 ชม.) |
| ตัดคลิป 5 ติด | ×1.5 drain | ตัดคลิป 5 อันโดยไม่ทำ activity คั่น | ทำ activity |
| comment แย่ 3 ติด | ×2 drain | ตอบ ⊖ 3 ครั้งติด | activity หรือตอบ ⊕ |
| comment ดี 3 ติด | ×1.25 recovery | ตอบ ⊕ 3 ครั้งติด | ครบ 1 วันเกม |
| viral 2 วันติด | ×2 recovery | คลิป viral สองวันติดกัน | ครบ 1.5 วันเกม (36 ชม.) |

> **Dormant (อยู่ใน config แต่ไม่ wire):** "คุย NPC แย่/ดี 3 ติด" — ขัดกับ §6/§7 ที่ lock ว่า
> dialogue ทางเดียวไม่มี choice จึงไม่มีทาง trigger — เก็บไว้เผื่อดึง NPC choice กลับจาก backlog

**ตัดออกแล้ว (decision A — "งานที่ส่งทันดีกว่างานที่ไม่เสร็จ"):**
- ~~คุยกับพ่อแม่เลือกช้อยส์ไม่ดี −25~~
- ~~คุยกับพ่อแม่เลือกช้อยส์ดี +40~~

ผลของ A: **mental นิ่งขึ้น** → Bad End ② กลายเป็น ending หายากที่ต้องจงใจไม่ฟื้นใจเลย
(consistent กับ Bad End ① ที่เป็น optional เหมือนกัน)

## 5. Endings (6 แบบ)

### Bad End Variants

| # | เงื่อนไข | Phase | หมายเหตุ |
|---|----------|-------|----------|
| ① | เงินไม่พอ โดนไล่ที่ 2 รอบ → กลับบ้าน โดนด่า → กลับไปเป็นทาสตลาดแรงงาน | 1, 2 | **Optional** — ต้องจงใจเล่นให้เงินหมด |
| ② | mental ≤ 0% → เก็บตัว เลิกทำ หายไปจากวงการ | 2, 3 | **Optional** — ต้องจงใจไม่ฟื้นใจ |
| ③ | choices ⊖ เยอะเกิน → โดนสังคมแบน/cancel หายจากวงการ | 3 | |

**สำคัญ — Roblox compliance:** ห้ามมีเนื้อหาฆ่าตัวตาย/ลอบฆ่าเด็ดขาด
ทั้ง ② และ ③ reframe เป็น **ความล้มเหลวเชิงสังคม/อาชีพ** ไม่ใช่ความตาย
(ถ้าไม่แก้ = เกมโดน moderate/ลบ = ส่งลิงก์ไม่ได้ = ตกรอบ)

**Bad ① vs ② ต่างกันชัด:** ① = แพ้เพราะปัจจัยภายนอก (เงิน) | ② = แพ้เพราะปัจจัยภายใน (ใจ)

### Trigger Conditions (ฉบับ %)

VidQ tier % = สัดส่วนของคลิปที่ถ่ายจริงทั้งหมด
Choices % = สัดส่วนของ choice ที่ตอบไปทั้งหมด (⊕ + ◎ + ⊖ = 100%)

| Ending | เงื่อนไข |
|--------|----------|
| **Bad ③** | `C ≥ 33% && B ≤ 33%` **\|\|** `⊖ ≥ 50% && ◎ ≤ 25%` |
| **Neutral ①** | `C ≤ 20% && B ≤ 33% && A ≥ 13% && S ≤ 13%` **\|\|** `\|⊖ − ⊕\| + ◎ < 25%` |
| **Neutral ②** | `C ≤ 26% && B ≤ 33%` **\|\|** `⊖ ≤ 37.5% && ◎ ≥ 25%` |
| **Good ①** | `C ≤ 16% && B ≤ 33% && A ≥ 30% && S ≤ 20%` **&&** `⊕ ≥ 62.5% && ⊖ ≤ 12.5% && ◎ ≤ 12.5%` |

**Priority order สำคัญ** — เช็คจากแย่สุด → ดีสุด, return ทันทีที่ match:
`Bad ① (เงิน) → Bad ② (mental) → Bad ③ → Good ① → Neutral ① → Neutral ②`
(ไม่งั้นเงื่อนไข overlap กันแล้ว trigger มั่ว)

**หมายเหตุ Good ①:** `⊕ ≥ 62.5%` ไม่ใช่เพดานจริง — เพราะ ⊖ ≤ 12.5% และ ◎ ≤ 12.5% บีบให้ ⊕ ต้อง ≥ 75% จริงๆ

**เลข .5:** เก็บไว้ในเอกสารออกแบบ (แม่นยำ) | สไลด์นำเสนอปัดกลมได้ (50/38/25/13/63)

**Neutral/Good ต้องถึง 1M ก่อน** — Bad End คือทางที่ไม่ถึง

**Endgame flow (จาก timeline):** 1M follower → งาน **BCA (Best Creator Award)** → cutscene → กลับไปหาพ่อแม่

## 9.4 NPC + arc เพื่อนร่วมทาง (lock 21 ก.ค. 2569 — PDF หน้า 3-4, reconcile กับ docs/12)

**เฟส = ระดับที่อยู่** (PDF หน้า 1 — ห้ามสับสน): **เฟส 1 = Homeless (ไร้บ้าน อยู่ข้างถนน/สะพานลอย)** / เฟส 2 = ห้องเช่าถูกๆ (Cheap Apartment) / เฟส 3 = บ้าน (House)
→ ฉากเฟส 1 ทั้งหมด (บท/cutscene/แมพ) ต้องเป็น**ข้างถนน ไม่ใช่ห้องเช่า**

**บทสนทนา NPC:** เฟสหลังมีมากกว่าเฟสแรก (แนวทางเดิม 2/4/4) — **ไม่ล็อกจำนวน** ตามระบบ % (§1)

**พ่อแม่:** ❌ **canon event "พ่อแม่โทรมา" ตัดออกทั้งหมด** เพราะพ่วงระบบ debate ที่ตัดไปแล้ว (ทำไม่ทัน)
→ แต่**พ่อแม่ยังเป็นแกนเรื่อง**: เป็นแรงจูงใจทั้งเกม (พิสูจน์ให้พ่อแม่ผิด) + ปรากฏใน **ฉากจบ** (Good ① = เข้าใจกัน / Bad ① = กลับบ้านโดนด่า)

**เพื่อนร่วมทาง 2 คน — auto มาตามเนื้อเรื่อง ไม่ต้องจ้าง ไม่เสียเงิน (คุณภาพสูง ตรงข้ามพนักงานจ้าง):**
- **เพื่อนคนแรก** (freshie ปี 1, หญิง 19) — **รู้จัก player ตั้งแต่เฟส 1** (เคยให้อาหารตอนไร้บ้าน) แต่ **recruit จริงตอนเฟส 2** — เริ่มอ่อนปวกเปียก แล้วโตแบบ **exponential** เป็นกำลังผลิตคุณภาพสูงสุด → **คือคนทรยศที่ 500K** ไปเข้าร่วมกับ Content Creator คู่แข่ง
  ผลตอนทรยศ: เสีย producer เกรดสูงสุดทันที (เจ็บเชิงระบบ) + mental −25 + drain mod ×1.25 24 ชม. + บทของ NPC ตัวนี้เปลี่ยนเป็นชุด "หลังทรยศ"
  *เหตุผลที่เลือกคนแรก: ผูกพันตามเวลาเล่นจริง เจ็บกว่าคนที่เพิ่งมา*
- **เพื่อนคนสอง** (video editor ชาย 27, เคยทำงานให้ CC คู่แข่งมาก่อน) **recruit เฟส 3** — **คนที่อยู่จนจบ** (contrast: เสียคนเก่า ได้คนใหม่ที่ไม่คาดคิด)
- **พนักงานจ้าง** = ปริมาณเยอะ คุณภาพต่ำกว่าเพื่อน จ้าง/ไล่อิสระ เสียเงินเดือน (§9.8)

**Ending 2 เกรดการผลิต** (กันทำไม่ทัน — จำนวนต้องครบ 6 ห้ามตัด เพราะกรรมการเช็คความสมบูรณ์):
- **เต็ม** (หลายมุมกล้อง + บทยาว): Good ①, Neutral ② — สองอันนี้ใช้โชว์ใน pitch/วิดีโอ
- **ย่อ** (กล้องมุมเดียว/จอดำ + text 3–4 บรรทัด): Bad ①②③, Neutral ① — engine เดิมรองรับอยู่แล้ว เหลือเวลาค่อยอัพเกรดทีละอัน

## 9.5 ระบบอัดคลิป + อุปกรณ์ 6 ระดับ (lock 21 ก.ค. 2569)

**อุปกรณ์:** เริ่มเกมได้ฟรีระดับ 1 (480p + 128GB) ซื้อเพิ่มสายละ 5 ครั้งในแอป Shop — **ตัด dropdown เปลี่ยน resolution ทิ้งถาวร** (ไม่มีประโยชน์ ระดับกล้อง = resolution เดียวตายตัว)

| ระดับ | กล้อง | ที่เก็บ | GB/คลิก* |
|-------|-------|---------|----------|
| 1 (เริ่ม) | 480p | 128 GB | 1 |
| 2 | 720p | 256 GB | 2 |
| 3 | 1080p | 512 GB | 4 |
| 4 | 1440p | 1 TB | 8 |
| 5 | 2160p | 4 TB | 16 |
| 6 | 4320p | 8 TB | 32 |

*GB/คลิก agent เลือก + ปรับตาม user feedback 21 ก.ค. ("เกมจะง่ายไป"): เต็ม storage ระดับเดียวกัน ~128 คลิก (ระดับ 5-6 ~256 คลิก จงใจ บังคับพึ่งโซน+พนักงาน) + **คลิกมี cooldown 0.6 วิ** กันสแปมแบบ simulator

> ⚠️ **กล้อง = ตัวคูณตอนอัดเท่านั้น ไม่แตะคุณภาพคลิป** (lock 26 ก.ค.) — VidQ tier มาจาก**คะแนน QTE ตอนตัดคลิป**อย่างเดียว ซื้อกล้องแพง = อัดเก็บ footage ได้ไวขึ้น ไม่ได้แปลว่าคลิปเกรดดีขึ้น

**สูตรต่อคลิก:** `GB = GB/คลิก[ระดับกล้อง] × (bonus 10%? ×2.4 : 1) × (ในโซน? ตัวคูณเฟส : 1)`
- **อัดนอกโซนได้** ที่ base rate (user ยืนยัน 21 ก.ค.)
- **Bonus proc "+2.4"** (PDF หน้า 7) สุ่ม 10% ต่อคลิก เกิดได้ทุกที่ และคูณซ้อนกับโซนได้

**โซนถ่าย (จุดแดง map PDF หน้า 4):** โซนถ่ายคลิป spawn เป็นวงพื้นที่ มีตัวคูณเขียนกลางวง + เวลา remaining ก่อนหาย — คลิกอัดในโซน × ตัวคูณตามเฟส: **เฟส 1 ×1.5 / เฟส 2 ×2 / เฟส 3 ×2.5** (ทุกจุดในเฟสนั้นเท่ากัน) โซนอยู่ 120 วิจริงแล้วสุ่มย้ายจุด — กัน player AFK จุดเดิม

**ตัด 1 คลิป = 32 GB คงที่ (lock 27 ก.ค.)** — footage ไม่พอ = เปิดมินิเกมตัดไม่ได้เลย (ไม่เสียใจ ไม่ได้คลิป)
> **ทำไมไม่ผูกกับ VidQ:** VidQ รู้ผลหลังตัดจบ (คะแนน QTE) แต่ footage ต้องหักตอนเริ่ม — ถ้าไปคิดทีหลังตามเกรด จะกลายเป็น "ตัดห่วย = ถูก / ตัดดี = แพง" คือลงโทษคนเล่นดี

ผลของ 32 GB: กล้อง L1 ต้องคลิก **32 ครั้ง/คลิป** (storage L1 เก็บได้ 4 คลิป) · กล้อง L6 คลิกเดียวได้ 1 คลิป
→ นี่คือเหตุผลเดียวที่ต้องอัปกล้อง (กล้องไม่แตะคุณภาพคลิป) และเหตุผลที่ต้องเดินหาโซน ×1.5–2.5

## 9.6 Comment ตามเกรดคลิป (lock 21 ก.ค. 2569 — PDF หน้า 8 ล่าง)

**การเกิด:** คลิปมี slot comment ⊖/◎/⊕ อย่างละ 1 ใบ (สูงสุด 3) — แต่ละ slot **ทอยแยกอิสระ** ตามเกรดคลิป (แต้มไม่รวม 100 จงใจ ไม่ออก = เงียบ, คลิปไม่มี comment ไม่แสดง):

| เกรด | ⊖ | ◎ | ⊕ |
|---|---|---|---|
| C | 40% | 25% | 10% |
| B | 40% | 36% | 40% |
| A | 20% | 30% | 40% |
| S | 5% | 40% | 50% |

**การตอบ (mental):** กดใจ — ⊕ +10 / ⊖ −10 (◎ กดใจไม่ได้) | ช้อยตอบ ⊖: ยอมรับปัญหา +10 / ประชด −5 / ด่า −10 | ช้อยตอบ ◎: ยอมรับปัญหา +10 / ประชด −5 | ปล่อยผ่านได้ ไม่มีผล
**UI:** สุ่มลำดับช้อยทุกครั้ง — ห้ามเรียงดี/กลาง/แย่ตายตัว (player จะกดแต่บนสุด)
**นับเข้า ending % (agent เสนอ ยังไม่ lock):** ใจ⊕/ยอมรับ→pos, ประชด→neu, ใจ⊖/ด่า→neg, ปล่อยผ่าน→ไม่นับ

## 9.7 Bank ⊖⊕ — ปรับงบจ่ายรายสัปดาห์ (lock 21 ก.ค. 2569 — PDF หน้า 9 บน)

⊖⊕ บนการ์ด = เพิ่ม/ลดยอดที่จะจ่ายต่อสัปดาห์ของการ์ดนั้น step ไม่เท่ากัน (step + ผลใจ agent เลือก):

| การ์ด | step | ช่วง (offset) | ผลตอนตัดรอบ 7 วัน |
|---|---|---|---|
| 🍚 ค่าอาหาร | ฿200 | −1 ถึง +3 | จ่ายเพิ่ม: ใจ +2/step / จ่ายลด: ใจ −4/step (กินถูก เจ็บกว่ากินหรูฟื้น) |
| 🏠 ค่าเช่า | ฿500 | −2 ถึง +2 | จ่ายเพิ่ม: ใจ +1/step / จ่ายลด: ใจ −3/step / **offset −2 = จ่ายต่ำกว่าสัญญา นับค้างเช่าทุกรอบแม้มีเงิน** (ทางลัดสู่ Bad End ①) |
| 👥 ค่าพนักงาน | ฿1,000 | 0 ถึง +5 | งบโบนัสทีม — ผลจริงรอระบบพนักงาน (§ staff ยังไม่ design) |

ยอดจ่ายจริง = ฐานตามเฟส (WeeklyExpenses) + offset×step, เน็ตคงที่ปรับไม่ได้. ผลใจเข้าเฉพาะวันตัดรอบ (ฝั่งบวกโดน recovery modifier คูณตามปกติ)

## 9.8 ระบบพนักงาน (StaffService) — lock 21 ก.ค. 2569

> ⚠️ ตัวเลขในภาพ PDF หน้า 9 (speed 18 / quality 50 / salary 20k / 10-20 video per day) = **mock วาดให้เห็น UI** ไม่ใช่ค่าจริง — ตัวเลขข้างล่างนี้ design ใหม่จากสมดุลเกม

### หลักการ
**2 สายต่างกันโดยเจตนา** (PDF หน้า 1): **เพื่อนร่วมทาง** = คุณภาพสูง, ฟรี, มาตามเนื้อเรื่อง, โต exponential | **พนักงานจ้าง** = ปริมาณเยอะ คุณภาพต่ำกว่า เสียเงินเดือน จ้าง/ไล่อิสระ
**คลิปพนักงาน = auto ครบวงจร** (อัด→ตัด→อัปเอง) ได้ follower + เงินเข้าเลย ไม่กิน footage/storage ของ player, **ไม่มี viral, ไม่คูณ mental** (อ่อนกว่าคลิปที่ player เล่นดีเสมอ)
**คลิปพนักงานนับเข้า VidQ% ของ ending ครึ่งเดียว (น้ำหนัก 0.5)** และ**สร้าง comment ปกติ** — ตรงเจตนาเฟส 3 ที่ player เปลี่ยนจาก "อัดคลิป" เป็น "ตอบโต้ผู้ชม" (PDF หน้า 1)

### ตัวเลข

**ผลิต:** `คลิป/วัน = speed / 20` | **cap 4 คนจ้างพร้อมกัน** (เพื่อนร่วมทางไม่นับ cap)
**follower/คลิป** = `FollowerBase[เฟสปัจจุบัน] กลางช่วง × tierMult` → พนักงานเดิมแรงขึ้นเองตามเฟส (phase คือตัวขับหลัก)
**เงิน/คลิป** = follower ที่ได้ × `MoneyRatePerFollower[เฟส]` (เหมือนคลิป player)

**quality → โอกาสได้ tier (สุ่มทุกคลิป):**

| quality | C | B | A | S |
|---|---|---|---|---|
| 0–40 | 60% | 30% | 10% | 0% |
| 41–70 | 20% | 45% | 30% | 5% |
| 71–90 | 5% | 25% | 45% | 25% |
| 91+ | 0% | 10% | 40% | 50% |

**roster จ้าง — ปลดล็อกด้วย เฟส **และ** follower (ต้องครบทั้งคู่):**

| slot | เงื่อนไขปลด | speed | quality | salary/สัปดาห์ |
|---|---|---|---|---|
| 1 | เฟส 2 + follower ≥ 15,000 | 20 | 35 | ฿8,000 |
| 2 | เฟส 2 + follower ≥ 40,000 | 35 | 45 | ฿15,000 |
| 3 | เฟส 3 + follower ≥ 150,000 | 50 | 60 | ฿30,000 |
| 4 | เฟส 3 + follower ≥ 450,000 | 70 | 80 | ฿60,000 |

- **pool คงที่** (ไม่สุ่ม stat) — balance ได้แน่นอน
- ปลดแล้วปลดเลย (เข้าเฟสถัดไปแล้วพนักงานเฟสเก่ายังจ้างได้)

**เพื่อนร่วมทาง (auto ตามเนื้อเรื่อง ฟรี ไล่ไม่ได้ ไม่นับ cap):**

| ตัว | มาตอน | speed | quality | หมายเหตุ |
|---|---|---|---|---|
| companion_1 | เฟส 2 (10K) | 20 → **45** | 30 → **75** | โต exponential ตอนเข้าเฟส 3 → **หายที่ 500K (ทรยศ)** |
| companion_2 | เฟส 3 (100K) | 40 | 85 | อยู่จนจบ |

**เงินเดือน:** หักรอบ 7 วันพร้อมค่าเช่า (§9.7 การ์ด staff = งบเสริม/โบนัส) — **จ่ายไม่ไหว = พนักงานจ้าง salary แพงสุดลาออกอัตโนมัติ** (ไล่ทีละคนจนจ่ายไหว) เพื่อนร่วมทางไม่ลาออก (ฟรีอยู่แล้ว)

**ทรยศ 500K:** `flags.betrayed = true` → companion_1 หายจากทีมทันที (เสีย producer quality 75 = แรงสุดตอนนั้น) + mental −25 + drain ×1.25 24 ชม.

### เช็ค balance (ทำไมไม่ OP)
slot 2 (speed 35) = 1.75 คลิป/วัน × ~2,000 follower (เฟส 2 กลาง) ≈ 3,500/วัน → ข้าม gate 10K→100K คนเดียวใช้ ~26 วันเกม (เร่งได้ ไม่โกง) | salary กิน ~40–50% ของรายได้ที่มันสร้าง = มีกำไรแต่ไม่ฟรี | คลิป auto ไม่มี viral/mental จึงแพ้คลิปที่ player ตั้งใจเล่นเสมอ

## 9.9 ที่อยู่ / ประตู / Tycoon / เสียง (lock 26 ก.ค. 2569)

### ที่อยู่ = **ปลดล็อกเพิ่ม ไม่ใช่ย้ายทิ้ง**
เฟสขึ้น = **ปลดที่อยู่ใหม่** แต่**กลับไปที่เก่าได้ตลอด** (แมพทั้ง 3 เฟสอยู่ในโลกเดียวกัน เดินไปมาได้)
- `Map_Phase1` (ข้างถนน/สะพานลอย) — เข้าได้ตั้งแต่ต้น
- `Map_Phase2` (ห้องเช่า) — ปลดที่ follower ≥ 10,000
- `Map_Phase3` (บ้าน) — ปลดที่ follower ≥ 100,000

**`Interact_Door` = ประตูเข้า/ออกที่อยู่** — กดแล้ว teleport ตัวละครไปอีกฝั่ง
- ประตูที่ยังไม่ปลด = กดแล้วขึ้นข้อความ "ยังเข้าไม่ได้ (ต้องมี X follower)"
- แต่ละบานต้องมี Attribute `Target` = ชื่อ Part ปลายทาง + `MinFollower` = เลขที่ต้องมี (0 = เข้าได้เลย)

### Bad End ① — โดนไล่ที่ (ตาม PDF หน้า 1)

### Tycoon ในบ้าน (เฟส 2 ขึ้นไป)
เหยียบปุ่ม `Buy_<ชื่อ>` → หักเงิน → `Item_<ชื่อ>` โผล่ + ปุ่มหาย + จำลง save (convention การวางโมเดล: docs/05 §3.5)

### เสียง — engine เสร็จแล้ว 26 ก.ค. (`AudioService.luau`)

  Ambient/   เสียงบรรยากาศซ้อนเพลง (Looped)     — ฝน/รถ/เสียงห้อง
  Voice/     blip ตอนพิมพ์บท (คลิปสั้นมาก ~0.1 วิ) — ชื่อ = ชื่อไฟล์บท เช่น Friend1, CC1, Hater, Default

**SFX ที่โค้ดเรียกอยู่แล้ว** (วางชื่อพวกนี้ = ดังทันที): `ui_click` (ทุกการกด) · `upload_done` · `viral` · `footstep`

crossfade 1.2 วิอัตโนมัติ · cutscene ล็อกเพลงไว้ไม่ให้โซนแย่ง · **ไม่มีไฟล์เสียง = warn ครั้งเดียวแล้วเงียบ เกมไม่พัง**

## บทเรียนสำคัญที่ได้จากการออกแบบ

- **ผูก logic กับ milestone ไม่ใช่จำนวนคลิป** — ยืดหยุ่นกว่า ไม่ต้องแก้ทั้งระบบเมื่อ pacing เปลี่ยน
- **Bad End เป็น optional challenge ดีกว่า fail state บังคับ** — เกมเข้าถึงง่ายขึ้นโดยไม่เสีย stakes
  และตัดปัญหาลูกโซ่ (limit คลิป/วัน, บังคับ pacing) ออกได้หมด
- **Roblox ห้ามเนื้อหาความตาย** — reframe เป็นความล้มเหลวเชิงสังคม emotional หนักเท่าเดิม
- **ตัวเลขใน UI = placeholder** อย่ายึดเป็น canon
- **Scope discipline** — ทีม 3 คน / 8 สัปดาห์ ตัดได้ตัดก่อน "งานที่ส่งทันดีกว่างานที่ไม่เสร็จ"
