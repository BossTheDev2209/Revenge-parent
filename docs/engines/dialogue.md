# Engine: Dialogue — บทคุย NPC (= cutscene **โหมด 2 "ฉากคุย"**)

**ไฟล์โค้ด:** `StarterPlayerScripts.UI.DialogueUI` (engine) · `StarterPlayerScripts.InteractBinder` (เลือกบท)
**ไฟล์เนื้อหา:** `ReplicatedStorage.Shared.Content.Dialogue.<ชื่อ NPC>` ← **ทีมแก้แค่ตรงนี้**
**หน้าตา:** กล้องนิ่ง + กล่องข้อความล่างจอ + ชื่อคนพูด + กดเร่งข้อความได้ (โหมด 1 "หนัง" อยู่ที่ [cutscene.md](cutscene.md))
**กติกา:** ทางเดียวแบบ Undertale — **มีช้อยได้แต่ห้าม branching** (design doc §7) ทุกช้อยตอบกลับสั้นๆ แล้ว**บรรจบเส้นเดิม**

---

## 1. เกิดขึ้นเมื่อไหร่

player เดินไปกด Part ชื่อ `Interact_NPC_0X` → **หยุดเวลาในเกม** → กล่องข้อความพิมพ์ทีละตัวอักษร → คลิกไปบรรทัดถัดไป → หมดบรรทัด → **เวลาเดินต่อ**

คลิกระหว่างพิมพ์ = โชว์ทั้งบรรทัดทันที (ข้าม typewriter)

**กล้อง (เพิ่ม 1 ส.ค. 2569):** กดคุย NPC จากทางไหนก็ได้ กล้อง tween มาโฟกัสหน้า NPC ให้อยู่กลางจอ · scroll wheel ปรับ zoom (ตามจำนวนระดับใน `zoomLevels`) tween ลื่น · จบบทกล้องคืนสู่ player · โค้ด `CameraFocus.luau` เรียกจาก `startDialogue` (ไม่ใช่ใน DialogueUI — engine เรนเดอร์กล่องเหมือนเดิม)
ปรับค่ากล้องที่ `Config.Dialogue`: `zoomLevels` (ระยะแต่ละระดับ) · `zoomDefault` · `camHeight` · `camTweenTime`

## 2. เขียนบทยังไง

**1 ไฟล์ = 1 NPC** ข้างในแบ่งเป็นช่วง (key ต้องเป็นชื่อพวกนี้เท่านั้น):

```lua
return {
    p1 = { "บรรทัด 1", "บรรทัด 2" },   -- บทตอนเฟส 1 (Homeless)
    p2 = { "..." },                      -- เฟส 2 (ห้องเช่า)
    p3 = { "..." },                      -- เฟส 3 (บ้าน)
    after = { "..." },                   -- บทหลังเพื่อนทรยศ (เฉพาะ Friend1/CC1)
    again = { "..." },                   -- บทตอนคุยซ้ำในเฟสเดิม (optional — ไม่มี = คุยซ้ำเล่นบทเต็ม)
    byLoc = {                            -- (เพิ่ม 12 ส.ค. 2569) บทแยกตาม state.npcLoc[actor] ตอนกดคุย
        bed = { "..." },                  --   แบบลิสต์ตรง: ทับ p<n>/again ทันที ไม่แยกครั้งแรก/ซ้ำ (คุยซ้ำที่ loc นี้ได้บทเดิมซ้ำ)
        park = { p = { "..." }, again = { "..." } }, -- แบบแยกครั้งแรก/ซ้ำในตัว (locSeen เป็นคนเลือก — เก็บ seenDialogue คีย์ผสมแยกจาก again เฟสปกติ)
    },
}
```
⚠️ ชื่อ key คุยซ้ำต้องเป็น **`again`** ไม่ใช่ `repeat` (`repeat` เป็น keyword Lua parse ไม่ผ่าน)

**`byLoc` (นอกเหนือ 5-key เดิม, เพิ่มทีหลัง):** ใช้เมื่อ NPC คนเดียวมีบทคุยคนละแบบตามที่อยู่ (เช่น ฟ้าใสคุยในห้อง ≠ คุยที่สวนสาธารณะ)
`InteractBinder.pickLines(mod, state, seen, loc, locSeen)` เช็ค `mod.byLoc[loc]` **ก่อน** `again`/phase-walk เสมอ (แต่หลัง `after` ถ้าทรยศแล้ว) — `loc` มาจาก `state.npcLoc[dialogueName]` ที่ `startDialogue` ส่งให้
`byLoc[loc]` เป็นได้ 2 แบบ: **ลิสต์ตรง** (`{ "..." }`) = ไม่แยกครั้งแรก/ซ้ำ (ยอมรับ trade-off คุยซ้ำได้เดิม) หรือ **`{ p = {...}, again = {...} }`** = แยกในตัว
แบบหลัง `locSeen` มาจาก `state.seenDialogue["<ชื่อบท>@<loc>"]` (คีย์ผสม, แยกจาก `seen`/`again` เฟสปกติสิ้นเชิง) — `startDialogue` mark ให้อัตโนมัติตอนคุยจบไม่ใช่เลิกคุยกลางคัน

**`cam` (เพิ่ม 12 ส.ค. 2569):** ใส่ในบรรทัดไหนก็ได้ (เหมือน `speaker`/`anim`) — ชื่อ Part กล้องที่วางด้วย `tools/CutsceneCamTool.plugin.luau` (`Workspace.CutsceneCams`, attribute `Ease`/`TweenTime`/`FOV` เดียวกับ cutscene mode 1)
ตัดกล้องไป Part นั้น **ทันทีที่บรรทัดนั้นขึ้น** (ไม่ใช่ timer แบบ CutscenePlayer — DialogueUI คลิกไปทีละบรรทัดเอง จังหวะตัดจึงผูกกับ "อยู่บรรทัดไหน" ไม่ใช่เวลาผ่านไปเท่าไหร่)
⚠️ **บทที่มี `cam` แม้แค่บรรทัดเดียว = `startDialogue` ไม่เรียก `CameraFocus.focus` ให้ทั้งบท** (เช็คอัตโนมัติ สแกนทุกบรรทัดก่อนเริ่ม) กันชนกับกล้อง zoom-หน้าปกติ — จบบทกล้องคืนที่เดิมให้เอง (`DialogueUI` เก็บ/คืน `CameraType`/`CameraSubject` เองถ้าเคยใช้ `cam`)

**1 บรรทัดในลิสต์ = 1 กล่องข้อความ** ที่ player ต้องคลิกผ่าน

### 1 บรรทัดเขียนได้ 3 แบบ

```lua
p2 = {
    "ข้อความเฉยๆ ไม่มีชื่อคนพูด",
    { speaker = "แม่", text = "[slow]มีชื่อขึ้นมุมซ้ายบนกล่อง" },
    { choices = {                                    -- ให้ player เลือก
        { text = "ขอโทษครับ",  tone = "plus",    reply = { "แม่มองแล้วถอนหายใจ" } },
        { text = "เงียบไว้",   tone = "neutral" },   -- ไม่มี reply = เลือกแล้วไปต่อเลย
        { text = "เถียงกลับ",  tone = "minus",   reply = { "…" } },
    } },
    "บรรทัดนี้เล่นต่อเสมอ ไม่ว่าเลือกอะไร",          -- ← บรรจบกลับเส้นเดิม
}
```

| field | ใส่อะไร |
|---|---|
| `speaker` | ชื่อคนพูด (ไม่ใส่ = ไม่มีชื่อขึ้น **และไม่โชว์หน้าตัวละครฝั่งซ้าย**) — ใส่ **`"คุณ"`** = player พูดคนเดียว (ไม่ใช่คิดในใจ ที่ยังใช้วงเล็บใน text ปกติ) โชว์หน้า player เองแทน NPC อัตโนมัติ |
| `ifSeen` | ชื่อบท NPC อื่น — โชว์บรรทัดนี้**เฉพาะเมื่อเคยคุยจบ** NPC นั้น (เช่น `ifSeen="แม่"` = พูดถึงแม่ได้ต่อเมื่อคุยแม่แล้ว) |
| `ifNotSeen` | ตรงข้าม — โชว์**เฉพาะเมื่อยังไม่เคยคุย** NPC นั้น |
| `choices[].text` | ข้อความบนปุ่ม (จำเป็น) — ปุ่มช้อยลอย**ขวากล่อง** (Genshin ref) |
| `choices[].tone` | `plus` ⊕ / `neutral` ◎ / `minus` ⊖ — ✅ **ล็อก 28 ก.ค. 2569: ไม่ผูก mental ถาวร** (เหตุผลล่าง) |
| `choices[].reply` | บทตอบกลับ ลิสต์เดียวกันทุกแบบ (ซ้อนช้อยในช้อยได้แต่**อย่าทำ**) |
| `choices[].teleport` | (เพิ่ม 12 ส.ค. 2569) ชื่อ Part ปลายทาง — เลือกช้อยนี้แล้ว **จบบทจริง** (ไม่ใช่เลิกคุยกลางคัน) ค่อยวาปให้ (docs/16 §L45 "เลือกกลับไปแมพเฟสก่อนๆ") |

⚠️ **ห้าม branching เนื้อเรื่อง** — ห้ามใช้ช้อยพาไปบทคนละเส้น เพราะ design doc §7 ล็อกไว้ + บทจะบานเกินเวลา
ช้อยมีไว้ให้ player รู้สึกมีส่วนร่วมกับ**บทเดิม** ไม่ใช่แตกเส้นเรื่อง — `teleport` เป็นข้อยกเว้นที่ตั้งใจ (design doc เองขอไว้):
เปลี่ยนแค่**ตำแหน่งที่ยืนตอนจบบท** ไม่ใช่เนื้อเรื่อง/บทพูด — ทุกช้อยยังพูดเส้นเดิม แค่คนละปลายทางตอนจบเฉยๆ
(`DialogueUI.show`'s `onDone(picks, quit, teleportTarget)` → `runDialogue` ใน `Main.client.luau` เป็นคนยิง `TeleportTo` ให้ ไม่ใช่ DialogueUI เอง — engine core ไม่รู้จัก ActionRouter)

### พฤติกรรมตอนคุย (แก้ 5 ส.ค. 2569)

- **ตัวผู้เล่นจาง เข้า/ออก** (ไม่ใช่จอดำแบบ cutscene) — เริ่มคุย: กล้องโฟกัส NPC + ตัวผู้เล่นจางหาย (`LocalTransparencyModifier` 0→1) · จบ/เลิกคุย: ตัวผู้เล่นกลับมาทึบ + คืนกล้อง+unfreeze · ตัวผู้เล่นหันหลังบัง NPC เลยจางออกตอนคุย
- **แถบหนังบน-ล่าง** ขึ้นตลอดบท (ขนาด/สีเดียวกับ cutscene mode 1) — คุย NPC = โหมดหนัง
- **ซ่อน GUI อื่น** ที่เปิดอยู่ตลอดบท (HUD/ปุ่มเซฟ/Tool ฯลฯ ไม่ให้บังการมองเห็น) — จำที่ปิดไว้ คืนตอนจบ
- **ล็อกเดิน + ปิด ProximityPrompt ทั้งหมด** ตลอดบท (`InteractLock`) — กด E/WASD ไม่โดน prompt/ไม่เดินตัว
  (เดิมกด E ในแอปคอมทะลุไปโดน prompt · เดินตัวได้ระหว่างคุย) · ใช้ convention `MoveLocked` เดียวกับ cutscene
- **ปุ่ม "← เลิกคุย"** มุมซ้ายบนใต้แถบหนัง — ออกจากบทกลางคัน **ไม่นับว่าคุยจบ** (ไม่ยิง `DialogueSeen`) คุยใหม่ได้บทเต็มเดิม
- **ป้ายชื่อเหนือหัว NPC** โผล่เฉพาะ**หลังคุยจบตัวนั้นแล้ว** (`seenDialogue` มี key) — ป้าย interact อื่นโชว์ปกติ

`InteractLock` ใช้ร่วมกับ PC UI ด้วย (เปิดคอม = ล็อกเดิน + ปิด prompt เหมือนกัน) · ref-count กันปลดเร็วตอนซ้อน

### ✅ ล็อก 28 ก.ค. 2569 — `tone` ไม่ผูก mental

**ทุกช้อยไปทางเดียวกันหมด ผลเท่ากันทุกอัน** — `tone` เป็นแค่ป้ายกำกับอารมณ์ที่เลือก ส่งกลับทาง `onDone(picks)` เฉยๆ ไม่มีระบบไหนอ่าน

**ทำไม:** ถ้าช้อยมีผลจริง = branching กลายๆ ชนกับ design doc §7 + ผลต่อ mental ต้องมีสูตรใน `docs/02 §3` ซึ่งล็อกไปแล้ว
input ⊕/◎/⊖ ที่**มีผลจริง**อยู่ที่ **comment เท่านั้น** (docs/02 §9.6) — ที่เดียว ไม่ซ้ำซ้อน

**ห้ามดึงกลับ** เว้นแต่ user สั่งเอง แล้วต้องแก้ design doc ก่อน ห้ามแก้เงียบ

### ระบบเลือกบทให้เอง — ไม่ต้องเขียนเงื่อนไข
| สถานการณ์ | ได้บทไหน |
|---|---|
| **คุยซ้ำในเฟสเดิม** (เคยคุยจบบทเต็มแล้ว) | `again` ถ้ามี — ไม่มี = เล่นบทเฟสปกติเหมือนเดิม |
| อยู่เฟส 2 | `p2` |
| อยู่เฟส 3 แต่ NPC ไม่มี `p3` | ถอยลงมาใช้ `p2` (ใกล้สุดที่มี) |
| **ทรยศแล้ว** (follower ≥ 500K) | `after` ทันทีทุกเฟส — NPC ที่ไม่มี `after` ใช้บทเฟสปกติ |

→ **วาง NPC ในแมพครั้งเดียวพอ** ไม่ต้องทำ NPC แยกต่อเฟส

**คุยซ้ำ (`again`) จำข้ามเซฟ:** คุยจบบทเต็มครั้งแรกของเฟส → เก็บใน `state.seenDialogue[ชื่อบท]=เฟส` (persist ในเซฟ) → คุยซ้ำเฟสเดิมได้ `again`
เฟสขยับ = เจอบทเต็มของเฟสใหม่รอบนึงก่อน แล้วค่อยซ้ำ (แบบ Undertale) · ไม่เขียน `again` = ไม่ regress เล่นบทเต็มซ้ำเหมือนเดิม

## 2.5 ท่าทาง / สีหน้า ของตัวละคร (Genshin ref — เพิ่ม 29 ก.ค. 2569)

ใส่ field เพิ่มในบรรทัดไหนก็ได้ **ไม่ใส่ = ตัวละครยืนเฉยเหมือนเดิม**

```lua
p2 = {
    { speaker = "เจ", text = "เอ่อ...", anim = "HeadScratch", face = "Nervous" },
    { speaker = "เจ", text = "ไม่ไหวแล้วนะ", pose = "Angry", face = "Angry" },  -- ท่า+หน้าค้าง
    { pose = "Idle", face = "Normal" },                           -- บรรทัดสั่งล้วน ไม่ขึ้นกล่องข้อความ
    { speaker = "เจ", text = "เขาว่าไงนะ", actor = "CC1", anim = "Smug" }, -- ให้ "ตัวอื่น" ขยับแทน
}
```

| field | ความหมาย |
|---|---|
| `anim` | ท่าเล่นครั้งเดียว (one-shot) |
| `pose` | ท่ายืนค้าง loop — ท่า loop เดิมของตัวนั้นถูกหยุดให้อัตโนมัติ |
| `face` | **สีหน้า** — ค้างจนกว่าจะสั่งหน้าใหม่ |
| `actor` | ใครขยับ ไม่ใส่ = **NPC ที่กำลังคุยด้วย** · `"player"` = ตัวผู้เล่น |

**จบบทแล้วท่าหยุด + หน้ากลับเป็นหน้าเดิมทุกตัวอัตโนมัติ** ไม่ค้างทิ้งไว้ในแมพ

### ทีมเตรียมท่ายังไง (ไม่ต้องแตะโค้ด)

1. อัปโหลด animation ใน Studio (Animation Editor → Export) ได้ asset id
2. สร้าง **Folder ชื่อ `Animations` ใน ReplicatedStorage** (ครั้งเดียว)
3. วาง `Animation` object ข้างใน ตั้ง `AnimationId` แล้ว **ตั้งชื่อ = ชื่อที่จะเรียกในบท**

```
ReplicatedStorage/Animations/
  Idle · Point · HeadScratch · Angry · Cry ...   ← ท่ากลาง ใครก็ใช้ได้
  Friend1/  Point · Cry ...                       ← ท่าเฉพาะตัว (ชื่อโฟลเดอร์ = ชื่อไฟล์บท)
  CC1/      Smug ...
```

ระบบหา **ท่าเฉพาะตัวก่อน** ถ้าไม่มีค่อยใช้ท่ากลาง → ทำท่ากลางชุดเดียวใช้ได้ทุกตัว แล้วค่อยเติมเฉพาะตัวทีหลัง

### ทีมเตรียมสีหน้ายังไง

**สีหน้าไม่ใช่ animation** — R6 เปลี่ยนอารมณ์ด้วยการ**สลับรูปหน้าบนหัว** (Decal) เลยแยกโฟลเดอร์กัน

1. วาดหน้า/หาไฟล์หน้า → อัปโหลดเป็นรูปใน Studio (เหมือนรูป UI ทั่วไป) ได้ asset id
2. สร้าง **Folder ชื่อ `Faces` ใน ReplicatedStorage**
3. ข้างในวาง **`Decal`** (ตั้ง `Texture` = asset id) หรือ **`StringValue`** (ใส่ `rbxassetid://...` ใน Value) ก็ได้ — ตั้งชื่อ = ชื่อที่เรียกในบท

```
ReplicatedStorage/Faces/
  Normal · Happy · Sad · Angry · Shock · Nervous     ← หน้ากลาง
  Friend1/  Angry · Cry                               ← หน้าเฉพาะตัว (ทับหน้ากลางชื่อเดียวกัน)
```

โมเดล NPC ต้องมี `Head` ที่มี Decal ชื่อ `face` (ตัวละคร R6 มาตรฐานมีอยู่แล้ว)

### ผิดแล้วเป็นยังไง
| ทำผิด | ผลลัพธ์ |
|---|---|
| ไม่มีโฟลเดอร์ `Animations`/`Faces` / พิมพ์ชื่อผิด | warn ใน Output · **บทเล่นต่อปกติ ตัวไม่ขยับ/หน้าไม่เปลี่ยน** |
| โมเดล NPC ไม่มี Humanoid หรือชื่อไม่ตรง `NPC_0X` | warn บอกว่าหาตัวไม่เจอ · บทเล่นต่อ |
| โมเดลไม่มี `Head.face` | warn บอกว่าไม่มีหน้า · ท่ายังเล่นปกติ |
| `anim`/`face` ไม่ใช่ข้อความ | **ไม่เล่นทั้งบท** + warn บอกบรรทัด |

## 3. tag กลางประโยค (ความเร็ว + ตัวหนา/เอียง)

แทรก tag ได้ตรงไหนก็ได้ในบรรทัด:

```lua
"ปกติ [slow]ช้าลงตรงนี้ [fast]เร็วขึ้น [normal]กลับปกติ · [b]ตัวหนา[/b] กับ [i]ตัวเอียง[/i]"
```

**ความเร็ว** (คุมจากจุดที่แทรกไปจนเจอ tag ถัดไป):

| tag | วิ/ตัวอักษร | ใช้ตอน |
|---|---|---|

## 5.5 หน้าตากล่องข้อความ (Undertale-lite ref — เพิ่ม 5 ส.ค., ปรับ 6 ส.ค. 2569)

**กล่องขนาดคงที่เป็น px ไม่ยืดตามข้อความ** — ข้อความยาวขึ้น = **ตัดขึ้นบรรทัดใหม่** ตัวอักษรขนาดเท่าเดิมตลอด
(เดิมใช้ `TextScaled` = ยิ่งพิมพ์ยาวตัวยิ่งเล็ก อ่านไม่ออก)

สี **จงใจให้ contrast น้อยกว่า Undertale จริง** (เทาเข้มอมม่วง + ขาวหม่น ไม่ใช่ดำ/ขาวล้วน) กันดูก็อปตรงๆ

ปรับขนาด/ตำแหน่ง/สีทั้งหมดที่ `Config.Dialogue.box` — ไม่ต้องแตะโค้ด:

| ค่า | ทำอะไร |
|---|---|
| `width` / `height` | ขนาดกล่อง (px) — สัดส่วนตอนนี้ ~5:1 (กว้าง:สูง) แบบกล่องหนัง |
| `bottomGap` | ห่างจากขอบล่างจอ |
| `textSize` | ขนาดตัวอักษร **คงที่** |
| `padding` | ระยะขอบใน |
| `portrait` | ด้านของช่อง viewport หน้าตัวละคร (px) |
| `border` | ความหนาขอบ |
| `bgColor` / `borderColor` / `textColor` | สีพื้น/ขอบ/ตัวอักษร (Color3) |

**ดอกจันนำหน้าประโยค** ระบบใส่ `* ` ให้เอง — ไม่ต้องพิมพ์ในบท
ใส่ `\n` กลางข้อความ = ขึ้นประโยคใหม่ **พร้อมดอกจันอีกตัว** (แบบ Undertale ที่มีหลายดอกจันในกล่องเดียว)

⚠️ **บทยาวเกินกล่อง = ตัวหนังสือหาย** (กล่องไม่ยืดให้แล้ว) — เจอแล้ว warn ใน Output บอกบทที่ยาวเกิน
วิธีแก้: **ซอยเป็นหลายบรรทัดในลิสต์** (กด click ทีละกล่อง) ไม่ใช่ย่อฟอนต์

### หน้าตัวละครฝั่งซ้าย — เรนเดอร์ 3 มิติจริง (เปลี่ยนจากรูปภาพ 6 ส.ค. 2569)

**ไม่ใช้รูปภาพวาดแล้ว** — ช่องซ้ายเป็น `ViewportFrame` เรนเดอร์**ตัวโมเดล NPC ตัวจริงในแมพ** (clone มาซูมที่หัว+บ่า)
ทุกครั้งที่บทขึ้นบรรทัดใหม่จะ clone รอบใหม่ → เสื้อผ้า/ทรงผม/สีหน้าที่ตั้งไว้ด้วย `face`/`pose` ก่อนหน้าติดมาด้วยอัตโนมัติ
**ไม่ต้องวาดรูปหน้าเอง** ทีมไม่ต้องทำอะไรเพิ่ม — วาง NPC ในแมพให้ถูก (docs/05 §3) ระบบหา rig จาก `actor` ให้เอง (ไม่ใส่ = คนที่กำลังคุยด้วย)

หา rig ไม่เจอ (เช่น `actor` พิมพ์ผิด หรือ NPC ตัวนั้นยังไม่ถูก stream เข้ามา) = **ซ่อนช่อง ข้อความเลื่อนไปกินที่แทน** ไม่พัง

โค้ดอยู่ `src/client/ModelViewport.luau` — module กลาง **reuse ได้กับของอื่น** เช่น preview สินค้าใน Shop UI (แผนต่อไป ยังไม่ได้ต่อสาย)
`ModelViewport.showBust(rig)` = โฟกัสหัว+บ่า (ใช้ที่นี่) · `ModelViewport.showModel(model)` = ซูมพอดีกรอบอัตโนมัติ (สำหรับของ/ไอเทมทั่วไป)

## 6. ผิดแล้วเป็นยังไง

| ทำผิด | ผลลัพธ์ |
|---|---|
| ลบ comma/วงเล็บ | **ไฟล์พัง เกมโหลดไม่ขึ้น** — ระวังสุด แก้แต่ข้อความในเครื่องหมายคำพูด |
| ไม่มี key ของเฟสนั้น | ถอยไปใช้เฟสก่อนหน้า / ไม่มีเลย = warn ใน Output ไม่มีอะไรขึ้น |
| พิมพ์ tag ผิด เช่น `[slowly]` | ใช้ความเร็ว normal เฉยๆ ไม่พัง |
| ลิสต์ว่าง `p2 = {}` | กดแล้วไม่มีอะไรขึ้น (ไม่ crash) |
| ช้อยไม่มี `text` / `tone` สะกดผิด | **ไม่เล่นทั้งบท** + warn บอกบรรทัด/ช้อยที่พัง |

**เช็คงานตัวเอง:** บอก agent ให้รันเทส — มีเทสคุมว่า NPC ทุกตัวต้องมีบทใช้ได้ที่เฟส 3 และ Friend1 ต้องมี `p1/p2/after` ครบ
