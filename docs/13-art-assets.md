# 13 — รูปที่ต้องวาดทั้งหมด (อิง PDF ครบ 10 หน้า · ขนาด "วาดที่/ส่งออกที่" ปรับใหม่ 27 ก.ค. 2569)

**ใครใช้ไฟล์นี้:** คนวาดรูป (ทุกสาย) + agent ที่ต่อ UI

---

## ⚠️ กฎขนาด — อ่านก่อนเปิดแอปวาด

### กติกาข้อเดียวที่ต้องจำ

> **วาดบน canvas ในคอลัมน์ "วาดที่" → ตอนเซฟค่อยย่อลงเป็นขนาดในคอลัมน์ "ส่งออก"**

**ทำไม:** เส้นปากกาแตกเป็นบันไดเพราะ canvas เล็กเกิน — pixel มันมีเท่านั้นจริงๆ ไม่ใช่ปัญหาปากกา
**ย่อลง = คมขึ้นเสมอ** (โปรแกรมเฉลี่ยสีให้ ขอบเรียบอัตโนมัติ) · **ขยายขึ้น = เบลอ/แตกเสมอ**

ทุกบรรทัดในไฟล์นี้ตั้ง "วาดที่" ให้**ด้านยาว ≈ 1024–2048 px** แล้ว ไม่ต้องคิดเอง วาดตามได้เลย

### ถ้าแอปวาด canvas ได้ไม่ถึงที่กำหนด
วาดที่ใหญ่สุดเท่าที่ทำได้ **แต่ห้ามต่ำกว่า 2 เท่าของขนาดส่งออก** — ต่ำกว่านั้นเส้นจะเริ่มเห็นบันได

### เพดานของ Roblox
**Roblox ย่อรูปที่ด้านยาวเกิน 1024 px อัตโนมัติ** → คอลัมน์ "ส่งออก" ไม่มีอันไหนเกิน 1024
(วาดที่ 2048 ได้ ไม่ผิด — แค่ต้องย่อเหลือ ≤1024 ก่อนอัป ไม่งั้น Roblox ย่อเองแบบคุมไม่ได้)

### UI ในเกมมี 2 ระบบ ขนาดคนละเรื่อง

| ระบบ | อยู่ไหน | พื้นที่จริง |
|------|---------|------------|
| **SurfaceGui** — แปะบนจอคอมจริงในโลก | UI PC ทั้งหมด (7 แอป + wallpaper) + เมนูสมุด/โปสเตอร์ | **canvas 1000 × 650 px** (จอ part 4 × 2.6 studs × 250 px/stud) |
| **ScreenGui** — ลอยทับจอผู้เล่น | HUD, ปุ่ม RETURN, cutscene, ปุ่มเมนู | จอผู้เล่นจริง (~1920 × 1080) |

**สัดส่วนจอคอม = 4 : 2.6 = 1.538 : 1** (ไม่ใช่ 16:9) → ภาพเต็มจอคอมทุกใบ = **1024 × 666**

### กติกา 5 ข้อ
1. **PNG พื้นหลังใส** ทุกไฟล์ (ยกเว้น wallpaper / background ที่ทึบได้)
2. ไอคอนเผื่อขอบใน ~8% ของด้าน กันโดนตัด
3. **ทุกคีย์ที่ลงท้าย `_fill` ต้องเป็นสีขาวล้วน** — โค้ดคูณสีเอง (ใส่สีมาแล้วเพี้ยน)
4. ต้องอ่านออกบน**พื้นเข้ม** (HUD พื้นดำโปร่ง 25%)
5. **ตัวเลข/ตัวหนังสือทุกตัวโค้ดพิมพ์ทับเอง — ห้ามวาดลงในรูป**

**ลำดับความสำคัญ:** 🅿️0 = ขาดไม่ได้ | 🅿️1 = ทำให้ดูจริงจัง | 🅿️2 = มีก็ดี ไม่มีก็ส่งได้

## ขั้นตอนหลังวาดเสร็จ

1. **ย่อเป็นขนาดคอลัมน์ "ส่งออก" ก่อน** แล้วเซฟ PNG
2. Studio → **View > Asset Manager > Images > Import** ลากไฟล์เข้า
3. คลิกขวารูป → **Copy Asset ID**
4. เปิด `ReplicatedStorage.Shared.UIAssets` → วางใส่คีย์ที่ตรงกัน:
   ```lua
   hud_follower = "rbxassetid://1234567890",
   ```
5. **ห้ามเปลี่ยนชื่อคีย์** — โค้ดหาไม่เจอ (คีย์ที่ยังไม่มีรูป ปล่อย `""` ไว้ได้ เกมไม่พัง)
6. กด Play เช็ค — รูปไม่ขึ้นให้ดู Output ว่ามี warn อะไร

**Roblox moderation:** รูปที่อัปต้องผ่านการตรวจ ~นาที–ชั่วโมง | **ห้ามใช้รูปมีลิขสิทธิ์/โลโก้จริง = ผิดกติกาแข่ง ตกรอบ**
